Containerized Static Website Deployment with Docker and CI/CD

A beginner DevOps project demonstrating how to containerize and deploy a static website using Docker, Nginx, Docker Compose, GitHub Actions, and GitHub Pages.

Technologies Used

HTML • CSS • Docker • Nginx • Docker Compose • GitHub Actions • GitHub Pages

Project Highlights

  • Containerized a static website using Docker and Nginx
  • Configured Docker Compose for simplified deployment
  • Implemented CI with GitHub Actions
  • Automated deployment to GitHub Pages (CD)
  • Published the project with a live public URL
